⚠️ Before Public Deployment Requirements

This project is an educational, local prototype for SNJB's KBJ College of Engineering. None of the following production safeguards are currently implemented:

  • Production Database: Replace atomic local JSON file with PostgreSQL / MySQL for concurrent write transactions and indexing.
  • HTTPS & TLS: Secure all HTTP traffic with SSL certificates to encrypt sensitive citizen and administrative cookies in transit.
  • Rate Limiting & DDoS Defense: Add request rate-limiting on submission and authentication endpoints to mitigate brute-force attacks.
  • CSRF Protection: Enforce synchronized anti-CSRF tokens for state-changing endpoints (PATCH and POST).
  • Role-Based Access Control (RBAC): Segment administrative responsibilities (e.g. Field Engineer, Ward Supervisor, System Administrator).
  • Administrative Approval Workflows: Manually verify government identities before activating newly registered admin accounts.
  • Automated Backups: Scheduled off-site incremental snapshots of databases and uploaded attachments.
